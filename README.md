# 🚀 AI Job Board

A full-stack AI-powered job board where job seekers can find jobs, match their skills using AI, and upload their resume.

## 🌍 Live Demo
👉 [ai-job-board-inky.vercel.app](https://ai-job-board-inky.vercel.app)

## ✨ Features
- 📋 Browse job listings
- 🔍 Search & filter jobs by title, company or skills
- 📝 Employers can post new jobs
- 🤖 AI Resume Matcher — match your skills to jobs with a score
- 📄 Resume upload and storage
- 🔐 Real authentication (signup, login, logout)

## 🛠 Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** Supabase (PostgreSQL)
- **Authentication:** Supabase Auth
- **Storage:** Supabase Storage
- **Deployment:** Vercel

## 🚀 Getting Started

### Clone the repo
git clone https://github.com/swagata-ghosh146/ai-job-board.git

### Run Frontend
cd frontend
npm install
npm start

### Run Backend
cd backend
npm install
node server.js
